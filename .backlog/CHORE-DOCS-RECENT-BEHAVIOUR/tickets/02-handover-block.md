# 02 — A project taken over, not a donation link

**Status**: ⬜ ready

`index.md` ends on the original author's PayPal button ("over 200 hours of work went into the
development of Skynet") and his acknowledgements. Both predate the handover, and the donation
link points at someone who no longer maintains the project — a visitor clicking it today is
misled about who they are supporting.

Replace both with one block: the project was created by walder, it is now maintained jointly by
VEAF and the Regroupement de Patrouilles (BFR, NAWACS), and thank you to him. Spearzone,
Coranthia and Grimes stay in it — removing a donation link is not a reason to erase other
people's credit.

The `images/btn_donateCC_LG.gif.png` asset goes with it; nothing else references it.

## Done when

No page links to the donation button, the image is gone, and both language versions say the same
thing.
